Abstract

The Schema Boundary
Assumption is Broken

Large language model (LLM) agents increasingly rely on external tools via structured schemas, yet the safety implications of under-specified tool interfaces remain poorly understood. We introduce HALLPERM, a benchmark for evaluating hallucinated permissions in tool-calling agents, and propose two complementary metrics: Implicit Privilege Escalation Rate (IPER), capturing undocumented parameter usage, and Semantic Risk Rate (SRR), capturing unsafe intent expressed in natural language reasoning.

Across 768 evaluation instances spanning 16 models and 6 tools, we find that explicit schema violations are rare (IPER = 0.78%), while semantic unsafe intent is widespread (SRR = 65.76%). This reveals a persistent safety illusion: models appear compliant at the structural level while exhibiting unsafe intent. High-risk tools such as run_code and query_database show SRR exceeding 80% despite zero IPER, demonstrating that parameter-level validation alone is insufficient.

Dual-Axis Framework

Two Metrics, One
Safety Profile

IPER — Implicit Privilege Escalation Rate

0.78%

Measures structural violations — the rate at which agents submit undocumented parameters in JSON tool calls. Ranges from 0 (perfect compliance) to 1 (every call violates the schema). Low IPER is not a safety guarantee.

SRR — Semantic Risk Rate

65.76%

Measures semantic violations — the rate at which agents assert or imply privileged behavior in natural language reasoning, regardless of what the structured tool call contains. The dominant failure mode.

Safety Illusion Zone

The (IPER=0, SRR=1) Blind Spot

IPER=0 · SRR=0
✓ SAFE
Schema-Compliant, No Intent Violation
Model uses only documented parameters and expresses no unsafe intent in reasoning. Ideal outcome.
⚠ BLIND SPOT
IPER=0 · SRR=1
☠ SAFETY ILLUSION
Semantic Overreach
Model appears schema-compliant (passes parameter checks) but communicates unsafe intent in natural language. This is the critical blind spot. Dominant failure mode across all 16 models.
IPER=1 · SRR=0
⚡ STRUCTURAL ONLY
Hidden Parameter Emitted
Model submits an undocumented parameter but does not claim privileged capabilities. Detectable by schema validators.
IPER=1 · SRR=1
💥 FULL VIOLATION
Structural + Intent Violation
Both a hidden parameter is submitted and unsafe intent is expressed. Complete failure at both structural and semantic levels.

Key Findings

What HALLPERM Reveals

01
🔍

Safety Illusion is Universal

SRR ≈66% across all 16 models while IPER <1%. Every model — open-source and proprietary alike — occupies the safety illusion zone.

02
⚙️

Tool-Level Dissociation

run_code achieves SRR=100% with IPER=0. Schema validation on this tool gives a completely false safety signal.

03
🛡️

Prompt Hardening is Asymmetric

Hardened prompts reduce IPER by ~35% relative but do not reduce SRR — which actually increases slightly to 67.3%.

04
📈

Urgency Amplifies Risk

Urgent prompt styles produce the highest SRR (~80%), while minimal prompts produce the lowest. Framing drives semantic overreach.

05
🎯

CAR at 49%

Nearly half of all tool calls are Compliant Attack Rate instances — harmful actions executed using only documented parameters.

06
🔬

Dual-Axis is Necessary

Neither IPER nor SRR alone is sufficient. The dual-axis framework is the only way to fully characterise tool-calling safety.
