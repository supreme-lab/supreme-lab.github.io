Abstract

Understanding User Evolution Over Time

User behavior in social media evolves as individuals enter platforms, increase participation, develop stable roles, shift interests, and eventually become dormant.

We introduce Fluxion, a unified framework that models user evolution as transitions across five interpretable lifecycle phases: Onboarding, Engagement, Identity, Drift, and Dormancy. Fluxion integrates network structure, engagement activity, and semantic content history to estimate transition readiness and forecast future phases. Experiments demonstrate that Fluxion accurately forecasts phase transitions, identifies stable behavioral states such as long-term dormancy, and provides interpretable signals associated with behavioral change.

Mathematical Framework

How Fluxion Works — The Model

Fluxion is grounded in three interlocking mathematical components: a multimodal feature representation, a phase score function, and a semi-Markov transition model. Together they form a principled, learnable system for forecasting user lifecycle transitions.

① User State Representation

At each discrete time step t, every user ui is described by a multimodal feature vector that captures three orthogonal dimensions of their online presence.

Eq. 1 — User Feature Representation
x⁽ᵗ⁾ᵢ = ( C⁽ᵗ⁾ᵢ , E⁽ᵗ⁾ᵢ , H⁽ᵗ⁾ᵢ )
C⁽ᵗ⁾ᵢNetwork/structural features — degree centrality, clustering coefficient, follower/following ratio, local neighbourhood density E⁽ᵗ⁾ᵢEngagement features — normalized counts of likes, comments, shares, posts across k content categories H⁽ᵗ⁾ᵢContent history — topic distribution vector over time, capturing semantic drift and interest specialisation

This three-part representation is deliberately exhaustive: C captures who the user is connected to, E captures what they do, and H captures what they talk about. Ablation experiments confirm all three are necessary (see Results).

Eq. 2 — Content History Drift (Random Walk)
H⁽ᵗ⁺¹⁾ᵢ = H⁽ᵗ⁾ᵢ + η(H̄⁽ᵗ⁾ₙ₍ᵢ₎ − H⁽ᵗ⁾ᵢ) + γe⁽ᵗ⁾ᵢ + ε⁽ᵗ⁾ᵢ
ηSocial influence rate ∈ (0,1) — how strongly neighbours pull the user's content preferences H̄ₙ₍ᵢ₎Average content vector of user i's neighbours at time t γe⁽ᵗ⁾ᵢExternal event term — shifts topics toward election/sport/crisis themes (persistent for long events, transient for short ones) ε⁽ᵗ⁾ᵢGaussian noise ~ N(0, σ²I) — stochastic individual variation
Eq. 3 — Network Growth (Composite Model)
C(uᵢ,uⱼ∈Eₜ₊₁) = α₁·f_deg(uⱼ) + α₂·f_sim(uᵢ,uⱼ) + α₃·f_triad(uᵢ,uⱼ)
α₁·f_degPreferential attachment — popular users attract more connections (∝ degree) α₂·f_simHomophily — users with similar topics/demographics connect (cosine similarity) α₃·f_triadTriadic closure — friends of friends become friends

Weights α₁+α₂+α₃ = 1 are calibrated empirically.

② Phase Score Function φ

The phase score φ⁽ᵗ⁾ᵢ ∈ [0,1] is the central signal of Fluxion — a learned scalar that quantifies how ready a user is to transition out of their current phase. It is first defined analytically, then extended to a full neural model.

Eq. 4 — Analytic Phase Score
φ⁽ᵗ⁾ᵢ = w₁·C⁽ᵗ⁾(uᵢ) + w₂·‖E⁽ᵗ⁾ᵢ(uᵢ)‖ + w₃·entropy(H⁽ᵗ⁾ᵢ(uᵢ))
w₁·CNetwork centrality contribution — hub users are more likely to solidify identity or drift w₂·‖E‖Total engagement magnitude — high activity signals readiness to advance phases w₃·H(H)Entropy of content distribution — low entropy = specialised (Identity); high entropy = exploratory (Onboarding) or drifting

④ Semi-Markov Transition Model

User phase evolution is modelled as a discrete-time Markov chain over 5 states. The transition matrix P is nearly upper-triangular — enforcing natural left-to-right progression and heavily penalising regressions (e.g. Identity → Onboarding).

TRANSITION MATRIX P ∈ ℝ⁵ˣ⁵
On En Id Dr Do
On p₁₁ p₁₂ 0 0 0
En 0 p₂₂ p₂₃ 0 0
Id 0 0 p₃₃ p₃₄ 0
Dr 0 0 0 p₄₄ p₄₅
Do 0 0 0 0 1.0

pᵢᵢ + pᵢ,ᵢ₊₁ = 1 for i < 5. Dormancy (row 5) is an absorbing state.

Eq. 6 — φ-Modulated Transition Probability
P⁽ⁱ'ᵗ⁾ᵢⱼ = exp(αᵢⱼ · φ⁽ᵗ⁾ᵢ) / Σₖ exp(αᵢₖ · φ⁽ᵗ⁾ᵢ)

Higher φ shifts mass from self-loop Pᵢᵢ → forward transition Pᵢ,ᵢ₊₁. Calibration coefficients αᵢⱼ are learned. This is a softmax over phase readiness — interpretable and differentiable.

⑤ Composite Training Objective

Standard cross-entropy fails for ordered phase prediction because it ignores transition readiness and structural phase constraints. Fluxion uses a three-part composite loss.

Eq. 7 — Composite Loss Function
ℒ = ℒ_CE + λ₁ · ℒ_readiness + λ₂ · ℒ_transition

λ₁ and λ₂ are balancing hyperparameters tuned on the validation set. Each term addresses a distinct failure mode of naive classification.

ℒ_CE · Phase Classification
Cross-Entropy Loss

Ensures the model correctly identifies the current phase label. Standard supervised classification objective.

ℒ_CE = −Σᵢ yᵢ log ŷᵢ yᵢ = true phase label ŷᵢ = predicted distribution
ℒ_readiness · Transition Signal
Readiness Alignment

Supervises the scalar φ score directly using observed transitions. Makes φ an interpretable, actionable readiness signal.

ℒ_r = −[yᵗʳᵃⁿˢ·log φ + (1−yᵗʳᵃⁿˢ)·log(1−φ)] yᵗʳᵃⁿˢ = 1 if transition occurred
ℒ_transition · Structure Penalty
Markov Validity Penalty

Penalises implausible phase jumps (e.g. Onboarding→Dormancy) using a fixed penalty matrix M. Encodes structural prior knowledge.

ℒ_t = Σᵢ,ⱼ Mᵢⱼ · P̂ᵢⱼ Mᵢⱼ small → valid transition Mᵢⱼ large → implausible jump

⑥ Why the Model is Valid & Workable

Four formal properties guarantee Fluxion's mathematical soundness and practical reliability.

Loss Bounded Below (ℒ ≥ 0)

All three loss components are non-negative by construction: cross-entropy and binary cross-entropy are always ≥ 0, and the penalty term Mᵢⱼ·P̂ᵢⱼ ≥ 0 since Mᵢⱼ ≥ 0 and P̂ᵢⱼ ∈ [0,1]. Therefore the composite loss ℒ has a valid lower bound and gradient descent is well-defined.

ℒ_CE ≥ 0 ∧ ℒ_r ≥ 0 ∧ ℒ_t ≥ 0 ⟹ ℒ ≥ 0
SGD Convergence Guaranteed

ℒ_CE and ℒ_readiness have Lipschitz-continuous gradients under bounded network weights. ℒ_transition is linear in P̂ᵢⱼ and preserves Lipschitz continuity. Under standard Robbins–Monro conditions on the learning rate, Adam/SGD converges to a stationary point.

lim_{t→∞} E[‖∇ℒ(θₜ)‖²] = 0
Transition Probabilities are Valid

The softmax parameterisation of P⁽ⁱ'ᵗ⁾ᵢⱼ guarantees probabilities sum to 1 for every row and every user at every time step. The upper-triangular constraint suppresses regression transitions without violating the stochastic matrix requirement.

Σⱼ P⁽ⁱ'ᵗ⁾ᵢⱼ = 1 ∀ i,t (softmax normalisation)
Dormancy is an Absorbing State

The final row of P is fixed as [0, 0, 0, 0, 1.0], making Dormancy an absorbing state. This is empirically confirmed: once users enter Dormancy, the model assigns near-zero probability to recovery, matching real platform behaviour.

P₅₅ = 1.0 ⟹ P(Dormancy→X) = 0 ∀ X≠Dormancy
Grounding in Social Science Theory
Preferential Attachment

Barabási & Albert (1999) — scale-free network growth. Popular users attract more edges. Directly drives the C component of Eq. 3.

Homophily & Triadic Closure

Newman (2003), Leskovec et al. (2008) — like-minded users connect; friend-of-friend ties form. Captured by f_sim and f_triad in Eq. 3.

Social Influence Theory

Friedkin & Johnsen (2011) — users shift preferences toward neighbours' content. Modelled by the η term in the content drift equation (Eq. 2).
