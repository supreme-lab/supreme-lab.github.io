User activities on social media deeply influence their subsequent interactions with content — generating measurable, predictable signals of interest. On platforms like Facebook, Twitter, and Reddit, users interact with posts from friends through comments and emoji reactions, reflecting nuanced levels of engagement that, if properly modelled, can drive far superior recommendation quality.

"Our hybrid approach solves the cold-start problem when there is a new user; for new items the cold-start problem will never occur, as we consider post category values."

SocialRec is built on a three-pillar signal architecture: user demographics (age, gender, occupation, education, location), post history (category-wise probability scores across 10 domains), and engagement signals (reactions, comments, shares weighted by category). Unlike prior systems that isolate one signal, SocialRec fuses all three.

The demographic weighting scheme is novel: rather than assigning fixed demographic weights, the system derives them dynamically from survey data — a user who prefers sports over politics receives a different demographic weight vector than one who engages primarily with technology. This personalised weighting is then incorporated into both matrix factorization and neural collaborative filtering pipelines.

We evaluate two model families — traditional Matrix Factorization (MF) and Neural Matrix Factorization (NeuMF combining GMF and MLP) — across three scenarios: demographic + history only, engagement only, and the full hybrid. NeuMF consistently outperforms across Loss, Hit Rate, and NDCG. Experiments are conducted on a synthetic dataset of 500 users across 2,000 posts spanning 10 content categories.

Methodology · Equations

The
Mathematical Framework

Four interlocking components: demographic weight calculation, matrix factorization for history, matrix factorization for engagement, and neural collaborative filtering via NeuMF.

4.1 · Weight Calculation

Dynamic Demographic Weights

Survey participants rate each post category (0–5) per demographic type. Two weighted rating aggregations produce ω¹_dm,l and ω²_dm,l for user and item latent factors respectively.

R¹_w,D(j,k)C(l) = Σₓ ωl · Rx,D(j,k)C(l) R²_w,D(j,k)C(l) = (1/K) Σₖ R¹_w,D(j,k)C(l) // ωl = inverse-distance weight of lth category ωl = Δ⁻¹ / Σ Δ⁻¹ₓ, where Δn = Rm − Rn
4.2a · Matrix Factorization (History)

User Demography + History Embeddings

Each user feature ρ_n,d combines weighted demographic attributes and post category probabilities. The dot product of U₁ and P₁ᵀ gives the history-based recommendation matrix R_dh.

ρn,d = ω¹_avg,i (demographic) cᵢ (post category) ω¹_avg,i = Σⱼ Xⱼ · ω¹_dm,j // Recommendation matrix: Rdh ≈ U₁ ⊙ P₁ᵀ
4.2b · Matrix Factorization (Engagement)

Engagement-Based Embeddings

User engagement matrix U₂ is built from weighted reactions (like, love, haha…), comments, and shares — all indexed by content category. Produces engagement score matrix R_e.

φᵢ,ⱼ = (Σᵣ wᵣ·ηᵣ + wc·ηc + ws·ηs) / (ηᵣ + ηc + ηs) // Item feature = category probability: ωᵢ,ⱼ = cᵢⱼ Re ≈ U₂ ⊙ P₂ᵀ
4.3 · Neural Matrix Factorization

GMF + MLP → NeuMF

GMF models linear latent interactions; MLP captures non-linear interactions via hidden layers. NeuMF concatenates both final layers and is pre-trained from GMF and MLP weights.

Φ_GMF = U₁ ⊙ P₁ Φ_MLP = aL(WᵀL(aL₋₁(…W²[U₂;P₂]+b₂))+bL) // Final prediction: r̂up = σ(hᵀ [Φ_GMF ; Φ_MLP])

Cold-Start Problem

Solving New User
Cold-Start via Similarity

When a new user has no post history or engagement, SocialRec falls back to demographic similarity — finding the k most similar existing users and transferring their recommendation scores.

The Problem

New User — Zero Activity History

If a user has just signed up with no posts and no engagement, R_dh and R_e both produce zero recommendation vectors. Standard matrix factorization fails completely for this user.

New items never trigger a cold-start because SocialRec uses content category probability scores rather than interaction history — a new post is immediately scoreable.

R_dh = 0 (no post history) R_e = 0 (no engagement) R_dhe → undefined for new user u
The Solution

Demographic Similarity Matching

Demographic similarity between the new user u and each existing user v is computed as a weighted average over α attributes (age, gender, occupation). Categorical matches give sⱼ = 1, mismatches give 0.

Sim(u,v)dm = Σⱼ sⱼ·ω(j)dm / Σⱼ ω(j)dm Top-k similar users → S_t, M_t Ru ≈ S_tᵀ · M_t ∈ ℝ¹ˣᵐ

The recommendation vector for the new user is a weighted combination of the top-k neighbours' recommendation scores — effectively borrowing their taste profiles.
